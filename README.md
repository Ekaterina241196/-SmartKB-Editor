# 🐕 Content Watchdog

**AI-агент для автоматического поиска устаревшего контента в Базе Знаний поддержки Авито.**

Проект создан для хакатона Avito AI Hackathon 2026.
Номинации: «Агент HAL 9000», «Автоматизируй это!», «AI-first подход».

## 🚀 Проблема
Продукт обновляется каждую неделю, а инструкции в базе знаний живут месяцами.
- Пользователи теряют доверие, когда инструкция не соответствует интерфейсу.
- Поддержка получает вал тикетов из-за «несуществующих кнопок».
- Ручная проверка тысяч статей после каждого релиза невозможна.

## 💡 Решение
Скрипт на Python, который:
1. Загружает тексты статей (из выгрузки или Confluence API).
2. Загружает релиз-ноты продукта (из Jira/Confluence).
3. Отправляет пары «Статья + Релиз» во внутреннюю LLM Авито.
4. Получает структурированный отчет о несоответствиях (термины, логика, UI).
5. Формирует таблицу приоритетов для редакторов.

## 🛠 Стек технологий
- **Язык:** Python 3.10+
- **AI:** Внутренний LLM Gateway Авито (через API)
- **Формат данных:** JSON / Markdown
- **Зависимости:** `requests`, `pandas`, `python-dotenv`

## ⚙️ Как запустить (Local Run)

### 1. Подготовка
Создайте файл `.env` в корне проекта:
```bash
LLM_API_KEY=your_internal_key_here
LLM_API_URL=https://llm-gateway.avito.ru/v1/chat/completions
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Запуск
```bash
python src/watchdog.py
```

В папке `output/` появится файл `report_YYYY-MM-DD.md`.
